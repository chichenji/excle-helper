## 三、AI 设计要点

- **供应商抽象**：DeepSeek / OpenAI 兼容接口 / 自定义地址 / 本地模型（Ollama）共用一套 `chat/completions` 协议。
- **密钥安全**：API Key 用 DPAPI（当前用户作用域）加密存于 `%APPDATA%\ExcleHelper\ai.bin`，明文不落盘、不进日志。
- **结构化输出 + 本地校验**：模型只产出 JSON 指令；公式先写进临时工作表试算，报错即判非法；
  `WEBSERVICE / RTD / CALL / EXEC / REGISTER.ID / DDE` 等会触发外部动作的函数一律拒绝。
- **先预览后落盘**：默认不自动写入；应用后可用「撤销上次操作」回退。
- **上下文最小化**：只发表格摘要（表头 + 列类型 + 前 N 行样本 + 规模），默认开启发送前脱敏；
  分批处理（30-50 行/批）避免超长。
- **线程安全**：网络请求全部在后台线程，Excel COM 只在 UI 线程；请求可随时取消。

## 四、质量评审记录

交付前做过一轮独立只读代码评审，逐条修复的问题：

| 问题 | 后果 | 处置 |
|---|---|---|
| 单选按钮控件类型枚举写错 | 功能不成立且失败被吞 | 改为 `xlGroupBox=4` / `xlOptionButton=7`，并统计未绑定数量 |
| 排名升降序判断写反 | 默认模式下最大值拿最差名次 | 改为 `if (desc) Reverse()` |
| 「重复值」条件格式公式放错参数位、用相对地址 | 规则报错或区间偏移 | 改用 Formula1 + 绝对地址 |
| 套打模板整块回写 | 模板公式被固化成常量 | 只回写真正替换过的单元格 |
| 日期域 5 个操作整块回写选区 | 选区内公式被静默转常量 | 新增 `Xl.WriteSkipFormula`：跳过公式格 |
| 日期序列号下界写成 20000 | 1954 年前日期被判非法 | 下界改为 `>= 1` |
| 插入分页符前无条件清空已有分页符 | 用户排好的分页被删 | 改为先询问 |
| 断外链逐格 COM 往返 | 大表长时间假死、跳过不告知 | 改用 `SpecialCells` 一次定位；跳过的表计入提示 |
| 多处 catch 报错后仍提示"已完成" | 用户无从判断是否生效 | 统一加成功标志位 |
| 引用方式切换会改字符串与函数名 | `="A1"` 被改写、`LOG10(` 变非法 | 按引号切分只处理字面量外，正则排除函数名 |
| 图片对齐是双重循环 | 大选区 + 多图形时假死 | 改用 `TopLeftCell/BottomRightCell` 先判相交 |
| 下拉来源与定义名称缺工作表名 | 跨表引用错、联动串清单 | 补 External 地址与名称去重 |

后续批次中由测试发现并修复的问题：

| 问题 | 后果 | 处置 |
|---|---|---|
| 右连接未排除左表未匹配行 | 行为等价于全连接 | 补 `type == 3` 跳过逻辑 |
| 右表独有行没有回填主键 | 追加行看起来没有 ID | 键值写回左表键列 |
| Ribbon 功能组超过 5 个 | Excel 折叠最后一组，按钮在 UI 中消失 | 合并为每页 5 组 |
| 图标缓存被调用方 Dispose | 后续取同一图标失败，可能表现为图标空白 | `Render` 改为返回位图副本 |
| AI 设置窗程序化触发预设 | 覆盖用户已填的接口地址 | 加抑制标记，仅手动切换时套用预设 |
| 缺失值处理默认当表头 | 无表头数据不会被填充 | 新增「首行是否表头」参数 |

合计 **103 项断言**，通过 UI Automation 真实点击功能区并校验单元格结果。

- 统一入口 `run-all.ps1`：逐套运行，套间清理 Excel 进程与「文档恢复」状态，失败重试一次。

- AI 全部走**本地 mock 供应商**，无外网也能回归；另有 `EXCLE_AI_*` 环境变量钩子。
- `ui-shot.ps1`：只渲染设计稿（面板、关于、AI 弹窗、图标总览），改界面时用，不跑回归。

## 六、自动化接口

安装后可从脚本或 VBA 直接调用任意功能：

```powershell
$o = [Runtime.InteropServices.Marshal]::GetActiveObject('ExcleHelper.Connect')
$o.RunOp('t.keep.cn')     # 执行任意已注册操作（tag 见功能总览）
$o.Ping()                 # 自检：返回 ops 数量与连接状态
```

VBA：`Set o = GetObject("ExcleHelper.Connect")`（启动时已发布到 ROT）。

环境变量钩子（便于自动化）：

| 变量 | 作用 |
|---|---|
| `EXCLE_SILENT=1` | 启动前设置，抑制所有提示框 |
| `EXCLE_TRACE=1` | 把加载/回调轨迹写入 `%TEMP%\exclehelper-load.log` |
| `EXCLE_SHOT=1` | 界面改为离屏渲染 PNG（设计评审用） |
| `EXCLE_AI_KEY` / `EXCLE_AI_ASK` / `EXCLE_AI_AUTOAPPLY` | 覆盖 AI 密钥 / 需求文本 / 跳过预览 |

多输入类操作支持**文件钩子**绕过对话框（自动化回归用）：
`%TEMP%\excle-jt-inputs.txt`、`excle-ql-inputs.txt`、`excle-ai-inputs.txt`、`excle-pf-inputs.txt`。
