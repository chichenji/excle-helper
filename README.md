# EXCLE助手 1.1

一个独立实现的 Excel 表格效率插件。**无会员、无账户、无联网校验、无功能门禁**。

> 功能规划、交付批次、质量评审与测试体系见 [`docs/功能规划与交付.md`](docs/功能规划与交付.md)。

## 快速开始

```powershell
# 1) 安装（只写 HKCU，无需管理员）
powershell -ExecutionPolicy Bypass -File .\install.ps1

# 2) 重启 Excel，功能区出现三个选项卡：EXCLE助手 / 格式与数据 / 工具与输出
```

从源码构建（需要 Windows 自带的 .NET Framework 编译器，无需 Visual Studio）：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1      # 产出 bin\ExcleHelper.dll
powershell -ExecutionPolicy Bypass -File .\install.ps1    # 注册到当前用户
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1  # 反注册（先导出 .reg 备份）
```

> 仓库里已附带构建好的 `bin/ExcleHelper.dll`，不想编译可以直接跑 `install.ps1`。

## 免责声明

本项目为**独立实现**的 Excel 效率工具：全部代码、图标与界面均自行编写，不依赖任何第三方组件或运行时。
AI 功能需要用户自备 API Key，密钥以 DPAPI 加密仅存本机，不上传任何第三方服务（除用户自行配置的模型接口）。

- 形态：单个 `ExcleHelper.dll`（约 800 KB），经典 COM 加载项
- 依赖：无（不需要 VSTO 运行时 / Office PIA / Aspose / NPOI / WebView2）
- 注册：仅写 `HKCU`，不需要管理员

## 二、前端（重做）

### 1. 功能区：3 个选项卡 / 21 个功能组

| 选项卡 | 功能组（每组 3-6 个全尺寸图标按钮） |
|---|---|
| **EXCLE助手** | 开始 · 文本 · 数值与日期 · 编辑 |
| **格式与数据** | 格式 · 提取与清洗 · 汇总统计 · 工作表与文件 |
| **工具与输出** | 录入与公式 · 打印 · 图片与模板 |

**排版规则**：组内顶层控件一律 `size="large"`（等高方块，行列齐整），细项全部收进下拉菜单；
每组不超过 5 个顶层控件，避免 Office 在空间不足时把大图标降级成小图标而造成参差。

> 只做 3 个页签是刻意的：Excel 里往往还装着其他插件，页签条容易被占满并折叠，页签越少越不会被藏起来。

### 图标：每个功能一个独立图形（无文字、无外部素材）

- **不用文字当图标**：全部是 GDI+ 线条绘制的图形（文档、漏斗、橡皮、剪刀、日历、时钟、打印机、图表、锁、盾牌…）
- **每个功能不同**：270 个功能 → **270 个不同图标**（已用脚本校验，0 重复）
- 组合体系 = **基础图形**（约 70 种，按功能域着色）+ **右下角实心角标**（圆/方/三角/菱形/箭头/勾叉…，区分同类操作）+ 可选删除斜杠
- 图形只占画布 80% 并居中，视觉更小更轻；Office 会按需缩放，小按钮也清晰
- 交付前用脚本统计图标唯一性，避免"一个图标套多个功能"

## 六、已知限制

1. 身份证 / 银行卡请先把单元格设为**文本**格式，否则 Excel 会把 18 位数字截成 15 位精度。
2. 合并、转置、随机排序等属于「取值重建」，不保留源格式；拆分工作表/按列值拆分**保留原格式**。
3. 合并多表按列位置对齐，不做字段名智能匹配。
4. 批量操前建议先保存——插件不接管 Excel 撤销栈。
5. 页签条拥挤时（第三方页签多），Excel 会把后加的页签折叠进溢出菜单，这是 Excel 行为。

## 八、回退系统（Excel 原生撤销捕获不到 COM 写入）

同类插件的通病：插件直接写单元格，按 Ctrl+Z 无效，**操作不可回退**。本插件自带回退：

- 每次操作前对「当前工作表 UsedRange + 余量」做快照（**公式/值 + 数字格式**一起存），保留最近 **20 步**
- `开始 → 回退`：撤销上次操作 / 重做上次操作 / **历史记录（多步回退）** / 清空回退历史
- 回退时同时处理：写右侧的连带内容（自动清理）、由该操作**新建的工作表**（自动回收）
- 快照用 `Range.Formula` 读取，所以**公式回退后仍是公式**，不会变成常量
- 工作表被重命名的情况不自动改名（只回退内容并提示），避免误删
- 选区过大（超过 25 万格）时本次不记录快照，避免卡顿

验证：`uia-verify4.ps1` → `pass=10 fail=0`（含公式保留、写右侧清理、新增表回收、重做往返）

## 十、AI 助手（一期）

`工具与输出 → AI 助手`：**生成公式 / 解释公式 / 公式纠错 / AI 面板 / 设置与测试**。

### 设计原则（为什么这样接才安全）

1. **API Key 而非账号登录**：DeepSeek 未开放第三方 OAuth，抓网页登录态会随时失效；
   插件用 **DPAPI（当前用户）** 加密存 `%APPDATA%\ExcleHelper\ai.bin`，明文不落盘、不进日志。
2. **一套协议覆盖全部供应商**：DeepSeek / OpenAI 兼容 / 自定义网关 / 本地 Ollama 都是
   `BaseURL + Key + 模型名` 三项配置（`ai.ini`）。
3. **模型只产出结构化指令，是否可信由本地校验决定**：
   - 要求返回 JSON（`formula / target / explanation / assumptions / confidence`）；
   - 公式先写进**临时工作表试算**，Excel 抛错即判非法；
   - `WEBSERVICE / RTD / CALL / EXEC / REGISTER.ID / DDE` 等会执行外部动作的函数一律拒绝；
   - **默认不自动写入**，先弹预览，点「应用」才落盘。
4. **上下文只发摘要**：表头 + 列类型（含数值范围）+ 前 N 行样本 + 区域规模；
   默认开启**发送前脱敏**（手机号/身份证/银行卡/邮箱/姓名）。
5. **AI 写入走 Ops 注册表** → 自动进入回退快照，**「撤销上次操作」即可回滚**。
6. **线程安全**：HTTP 全部在后台线程，Excel COM 只在 UI 线程；请求中可取消。

### 自动化测试钩子

| 环境变量 | 作用 |
|---|---|
| `EXCLE_AI_KEY` | 覆盖 API Key（回归测试用） |
| `EXCLE_AI_ASK` | 覆盖"需求输入框"内容（免弹窗） |
| `EXCLE_AI_AUTOAPPLY=1` | 跳过预览直接按"应用"处理 |

`uia-verify6-ai.ps1` 用本地 mock 供应商（`HttpListener`）覆盖：正常返回、危险函数、非 JSON、401、
设置窗回显——**无外网、无真实额度也能跑回归**。

### 已修复的实例

设置窗打开时会把用户填的接口地址**覆盖**成预设默认值（程序化选中下拉框触发了预设逻辑）——
已加抑制标记，仅用户手动切换供应商时才应用预设。

## 十一、多表关联（批次 A1）

`格式与数据 → 汇总统计 → 多表关联`：这是表格工具里最常用的能力之一，
也是本插件此前最大的空白。

| 功能 | tag | 说明 |
|---|---|---|
| 多表关联合并（JOIN） | `jt.join` | 按主键做**左/内/右/全**连接；重复键取首条并在结果里提示 |
| 按主键刷新字段 | `jt.update` | 用来源表按主键覆盖同名列；未匹配行自动标色 |
| 记录级合并 | `jt.group.merge` | 同键多行合并成一行，多值用连接符拼接（组内去重） |
| 列名对齐追加 | `jt.attach` → `jt.append` | 多表按**列名**（而非位置）对齐后追加，列名冲突自动去重 |
| 一键生成透视表 | `jt.pivot` | 生成**原生 PivotTable**；区域设置差异导致失败时自动退回静态交叉表 |
| 交叉表（行转列） | `jt.crosstab` | 静态交叉表，自带行列合计与总计 |

### 自动化测试钩子

多输入类操作无法用对话框做自动化，因此提供文件钩子：

```
%TEMP%\excle-jt-inputs.txt
left=左表!A1:C4
right=右表!A1:C4
keyLeft=1
keyRight=1
type=1        ← 1左 2内 3右 4全
```

优先级：文件 &gt; 环境变量（`EXCLE_JT_LEFT/RIGHT/OPTS`）&gt; 对话框。同一 Excel 会话内可反复改写，
`uia-verify7-join.ps1` 用它覆盖了 6 个场景（19 项断言）。

### 修掉的两个语义缺陷

1. **右连接未排除左表未匹配行** —— 会把左表独有行也带进结果（等价于全连接）；
2. **右表独有行没有回填主键** —— 追加行整行看起来没有 ID。

### 统一回归入口

`run-all.ps1`：逐套运行并**在套间强制清理 Excel**（此前连续跑六套会互相污染状态），
`Click-Ribbon` 增加了 3 次重试以容忍菜单动画时序。

## 十四、AI 二期 / 三期

### 顺带修掉的一个真 bug

`Glyphs.Render` 之前返回**缓存里的同一个 Bitmap 实例**，而面板/图标总览用 `using` 会把它 Dispose ——
之后任何再取同一图标的调用都会拿到"已释放对象"（`DrawImage` 抛 `ArgumentException`），
**在功能区里就可能表现为图标空白**。现在改为每次返回副本，图标渲染 0 失败。
